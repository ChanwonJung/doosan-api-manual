4. Applications Extensions
==================================
This section provides an overview of **extended application functions** available in the Doosan Robotics API.  
It focuses on specialized features beyond basic motion and control, such as **welding, calibration, and motion assistance**. 

These extensions are designed to support advanced automation tasks and enable flexible process customization  
for various industrial applications, including welding automation and sensor-based control.
