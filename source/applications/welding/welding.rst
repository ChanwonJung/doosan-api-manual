4.1 Welding Application
==============================
This section defines all API commands related to **robotic welding operations**.  
It includes functions for weaving path configuration, analog and digital welding interfaces, EtherNet/IP communication,  
monitoring signal control, calibration measurement, and motion assistance.  

.. figure:: /tutorials/images/welding/welding.png
   :alt: welding
   :width: 80%
   :align: center

   *Source by* `DoosanRobotics product-solutions/welding <https://www.doosanrobotics.com/en/product-solutions/solution/process/welding/>`_

.. raw:: html
      
   <br>

These APIs enable seamless integration between the robot and external welding equipment,  
allowing precise control of welding parameters and adaptive real-time adjustments during operation.
