2. Definitions
================

This section is the canonical reference for **types and definitions** used across the DRFL.
Each category follows the **exact declaration order of its source header** to keep code and docs in lock-step.

- **Constants & Enumeration Types**: defined in ``DRFC.h``  
- **Data Structures**: defined in ``DRFS.h``
- **Callback Functions**: defined in ``DRFL.h`` and ``DRFLEx.h``
