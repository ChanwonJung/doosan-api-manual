2.1.5 I/O Configuration Constants (Version 3)
-------------------------------------------------

These constants extend the I/O capacity for DRCF version 3 controllers.

.. list-table::
   :widths: 30 20 50
   :header-rows: 1

   * - **Name**
     - **Value**
     - **Description**
   * - NUM_DIGITAL_V3
     - 32
     - Number of digital I/O channels on the controller (version 3).
   * - MAX_DIGITAL_BURST_SIZE_V3
     - 32
     - Maximum number of digital channels that can be read or written in a burst (v3).
   * - NUM_SAFETY_V3
     - 16
     - Number of safety-related I/O points (v3).
   * - NUM_SAFETY_IN_V3
     - 3
     - Number of safety input channels (v3).
