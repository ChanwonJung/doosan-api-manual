2.1.3 String Size Constants
----------------------------------------

.. list-table::
   :widths: 30 20 50
   :header-rows: 1

   * - **Name**
     - **Value**
     - **Description**
   * - MAX_STRING_SIZE
     - 256
     - Maximum size for text buffers and general string storage.
   * - MAX_SYMBOL_SIZE
     - 32
     - Maximum length for symbol names such as tool, TCP, or Modbus identifiers.
