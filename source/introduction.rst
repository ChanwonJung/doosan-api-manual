1. Introduction
================

Welcome to the **Doosan Robotics API Manual**.

The Doosan Robotics API was developed with the programming language C/C++, and can be used to directly control the Doosan robot controller from a user application, not from a teach pendant. 
This API manual describes the API functions.

The contents of this manual are current as of the date this manual was written, and product-related information may be modified without prior notification to the user.

For more information on the revised manual, please visit our Robot LAB website. (https://robotlab.doosanrobotics.com/)

If you are using an **earlier version of the API**, please refer to the corresponding documentation at the link below: |br|
`View Previous API Manuals (v1.33 and earlier) <https://manual.doosanrobotics.com/en/api/1.33/Publish/>`_
