5. Programming Instructions
==========================================
This section provides important **precautions and guidelines** for programming the robot system.  
It outlines the required programming sequence, safe execution procedures, and control limitations  
that must be observed when developing applications using the Doosan API.  

Following these instructions ensures **reliable program behavior**, prevents unexpected motion,  
and helps maintain system safety during operation.
