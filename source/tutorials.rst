6. Tutorials
==============
This section provides **hands-on tutorials** for using the Doosan Robot API,  
guiding you through executing API functions in both **real** and **virtual** environments.  
All tutorials can be built and executed on both Windows and Ubuntu.

Detailed setup procedures, such as API installation, library linking, build instructions,  
and Docker environment configuration, are already covered in
:ref:`Chapter 1.3 Environment Setup <environment_setup>`.

This chapter focuses instead on **the execution flow and the structure of tutorial examples**.
