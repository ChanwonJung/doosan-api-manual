6.6 Scenario-based Examples
===================================

The **Scenario-based Examples** section provides complete, runnable examples  
that integrate the various API features introduced in previous tutorials.  

Each scenario demonstrates how multiple functions such as motion control,  
DRL execution, welding operations, and real-time control  
can be combined into a cohesive workflow.
